# 🇩🇪 Немецкий язык как зеркало истории: диалекты, норма и идентичность

Академический исследовательский веб-сайт, посвященный диахроническому и социолингвистическому исследованию немецкого языка, подготовленный для развертывания на **GitHub Pages**.

> *«Политическая раздробленность германских земель исторически породила колоссальное диалектное многообразие. Впоследствии письменная и устная нормы (деятельность Мартина Лютера, кодификации Конрада Дудена и Теодора Зибса) сложились как вынужденный ответ на эту раздробленность. Вопреки унификации, современные немецкие диалекты не исчезли, а трансформировались в ключевые носители региональной идентичности и культурного кода (включая феномен диалектов немцев Казахстана)».*

## 🚀 Пошаговое руководство по развертыванию на GitHub Pages

### Шаг 1. Создание репозитория на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Задайте имя репозитория:
   - Либо специальное имя `username.github.io` (где `username` — ваш никнейм на GitHub), тогда сайт будет доступен по адресу `https://username.github.io/`.
   - Либо проектное имя, например `german-dialects-history`, тогда сайт откроется по адресу `https://username.github.io/german-dialects-history/`.
3. Сделайте репозиторий **Public** (публичным).

### Шаг 2. Загрузка файлов
Склонируйте репозиторий локально или загрузите файлы через веб-интерфейс GitHub:
```bash
git init
git remote add origin https://github.com/username/username.github.io.git
git add .
git commit -m "feat: initial commit - academic website German Dialects & Identity"
git branch -M main
git push -u origin main
```

### Шаг 3. Включение GitHub Pages в настройках
1. Откройте в репозитории вкладку **Settings** (Настройки).
2. В левом боковом меню выберите пункт **Pages**.
3. В блоке **Build and deployment** $\to$ **Source** выберите:
   - **Deploy from a branch**
   - Branch: `main` (или `master`)
   - Folder: `/ (root)`
4. Нажмите **Save**.
5. Через 1–2 минуты GitHub сгенерирует работающий сайт. Подробнее см. [официальное руководство GitHub Pages](https://docs.github.com/en/pages/quickstart).
