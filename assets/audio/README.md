# Аудиоматериалы и фонетические примеры проекта (assets/audio)

Данный каталог содержит транскрипции IPA и ссылки на эталонные аудиообразцы немецких диалектов, а также конфигурацию для воспроизведения через браузерный синтезатор речи (Web Speech API).

## 1. Пары изоглоссы Бенратской линии (maken / machen)
- **Север (Нижненемецкий / Plattdüütsch)**: `maken` [ˈmaːkn̩], `ik` [ɪk], `dat` [dat], `Appel` [ˈapəl], `Water` [ˈvaːtɐ]
- **Юг и Центр (Верхненемецкий / Hochdeutsch)**: `machen` [ˈmaxn̩], `ich` [ɪç], `das` [das], `Apfel` [ˈapfl̩], `Wasser` [ˈvasɐ]

## 2. Онлайн-архивы и аудиозаписи
1. **Forschungszentrum Deutscher Sprachatlas (REDE / Марбург)**:
   - Аудиозаписи чтений 40 предложений Венкера (*Wenkersätze*) на сотнях локальных диалектов: [https://regionalsprache.de/en/home.aspx](https://regionalsprache.de/en/home.aspx).
2. **Atlas zur deutschen Alltagssprache (AdA)**:
   - Интерактивные карты произношения и лексики: [https://www.atlas-alltagssprache.de](https://www.atlas-alltagssprache.de).
3. **Plautdietsch-Freunde e.V.**:
   - Аудиозаписи и образцы речи меннонитов (включая переселенцев из Казахстана): [https://www.plautdietsch-freunde.de](https://www.plautdietsch-freunde.de).
